# Case Técnico — Ciência de Dados

Case desenvolvido como parte de um processo seletivo para estágio em Ciência de Dados.

## Objetivo

Processar dados de compras e pedidos utilizando Apache Spark com PySpark, realizando:

- deduplicação dos dados;
- validação entre compras e pedidos;
- análise de compras por cliente;
- identificação do método de pagamento mais utilizado;
- identificação dos produtos mais vendidos;
- análise das datas com maior faturamento.

A segunda etapa apresenta uma proposta de arquitetura escalável para processamento de grandes volumes de dados, considerando qualidade, observabilidade e princípios de Data Mesh.

## Tecnologias

- Python
- PySpark / Apache Spark
- Git
- GitHub
